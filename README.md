# Fernando Thomaz · Fotografia

Portfólio online de fotografia especializado em esportes (basquete e futebol) e retratos.

🔗 **Acesse o site:** [https://thomazip.github.io/portfolio-fotografia/](https://thomazip.github.io/portfolio-fotografia/)

## 📷 Sobre o Projeto

Site estático responsivo desenvolvido com HTML5, CSS3 e JavaScript puro, otimizado para carregamento rápido e alta fidelidade visual em dispositivos móveis e desktop.

- **Tema:** Suporte a modo claro e modo escuro automáticos
- **Galerias:** Esportes, Retratos e Outros Trabalhos
- **Contato:** Informações e redes de contato
- **Deploy:** GitHub Pages
